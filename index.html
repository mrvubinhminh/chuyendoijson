How to use this tool

Excel to JSON

  1. Ensure you have the "Excel to JSON" tab selected.
  2. Click the dashed upload area or drag and drop an Excel file (.xlsx, .xls, or .csv).
  3. If your file contains multiple sheets, a dropdown will appear. Select the specific sheet you want to convert.
  4. The tool will automatically process the sheet. The first row of your Excel file will be used as the JSON keys.
  5. Review the generated JSON in the right panel.
  6. Use the Copy button to send it to your clipboard, or Download to save it as a .json file.
Note: Empty rows at the end of the sheet are ignored. Dates might be formatted as strings or numbers depending on how they are stored in Excel.

JSON to Excel

  1. Switch to the "JSON to Excel" tab at the top.
  2. Paste your JSON data into the editor on the left. You can also use the "Load File" button to read a .json file from your computer.
  3. The JSON must be an array of objects (e.g., [{"name": "John"}, {"name": "Jane"}]).
  4. The tool will instantly validate the JSON. If valid, a quick preview of the table headers and first few rows will appear on the right.
  5. Optionally, customize the Sheet Name and output File Name.
  6. Click the green "Generate & Download Excel" button to save the file to your device.
Privacy: All processing is done 100% locally in your browser. No data is ever sent to an external server.

Tính năng Trích xuất LaTeX (Dành cho Giáo viên)

Công cụ này được thiết kế chuyên biệt để bóc tách ngân hàng câu hỏi Toán từ định dạng LaTeX chuẩn (`ex`, `bt`) thành dữ liệu bảng (Excel/JSON) một cách sạch sẽ.

  • Hỗ trợ các dạng: Trắc nghiệm 4 lựa chọn (\choice), Trắc nghiệm Đúng/Sai (\choiceTF), và Trả lời ngắn (\shortans).
  • Nhận diện đáp án: Tự động tìm thẻ \True trong các phương án hoặc nội dung trong \shortans{} để xuất ra cột Đáp án.
  • Lọc nhiễu: Tự động loại bỏ các lệnh định dạng dư thừa như \immini, \noindent, \begin{center}, giữ lại cấu trúc toán học thuần túy.
  • Xử lý Hình vẽ: Toàn bộ các đoạn mã \begin{tikzpicture}...\end{tikzpicture} sẽ được tách riêng ra một file .txt để bạn tải về, giúp bảng Excel không bị nặng và rối. Trong file Excel/JSON sẽ để lại dấu [HÌNH VẼ TIKZ].
